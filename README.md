# Beyond L2 — Project Page

Project page for *Beyond $L_2$: Generalizing Abductive Latent Explanations to Diverse Prototype-Based Architectures* (ECML-PKDD 2026), a follow-up to [Formal Abductive Latent Explanations for Prototype-Based Networks](https://formal-ale.github.io/) (AAAI 2026).

Built with the [Academic Project Page Template](https://github.com/eliahuhorwitz/Academic-project-page-template) (Bulma + vanilla JS, no build step). Edit `index.html` directly; static assets live under `static/`.
